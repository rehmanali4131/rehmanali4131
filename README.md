## About me

I’m an AI Engineer at **Meissasoft**, working across model development, backend engineering, and deployment. I take ideas through data pipelines, model integration, APIs, and interfaces to build applications that work in production.

My focus is on **LLMs, agent workflows, RAG, and computer vision**, with attention to the engineering around them: permissions, tenant isolation, asynchronous processing, and observability.

## What I build

- **AI agents** that connect to real tools, stream their progress, and request human approval before sensitive actions.
- **Retrieval systems** that turn private documents and website content into useful, contextual answers.
- **Computer vision and generative AI** applications using model training, multimodal embeddings, and GPU inference.
- **Full-stack AI products** with Python APIs, React/Next.js interfaces, background workers, and production monitoring.
